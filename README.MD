# 🚗 Dashboard Inteligente de Sinistros

Dashboard desenvolvido para análise de dados de sinistros de uma frota de veículos.

> 🚧 Projeto em desenvolvimento

## 🛠️ Tecnologias

- Python
- Pandas
- Plotly
- Streamlit
- Git
- GitHub

## 📊 Indicadores

- Total de sinistros
- Prejuízo total
- Tempo médio de resolução
- Percentual de sinistros finalizados

## 📈 Análises

- Evolução mensal dos sinistros
- Volume de sinistros por estado
- Prejuízo por gravidade
- Volume de sinistros por tipo de acidente

## 🚀 Como executar

```bash
pip install -r requirements.txt
streamlit run app.py
